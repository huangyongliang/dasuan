# 大蒜笔记 (Dasuan Notes)

一个基于微信小程序云开发的极简笔记应用，支持Markdown编辑、图片上传、公开分享及匿名树洞功能。

## 主要功能

### 1. 笔记管理 (My Notes)
*   **创建/编辑**：支持 Markdown 语法，实时字数统计，支持上传图片。
*   **隐私设置**：可选择“公开”(Public) 或 “私有”(Private)。
    *   **私有笔记**：仅自己可见。
    *   **公开笔记**：需经过管理员审核通过后，才会出现在“公开广场”。
*   **状态流转**：草稿 -> 审核中 -> 已发布 -> (申请删除) -> 已删除。

### 2. 公开广场 (Square)
*   展示所有用户发布的、且审核通过的公开笔记。
*   所有人可见，支持下拉刷新。
*   **评论功能**：
    *   **公开评论**：支持对公开笔记进行评论。
    *   **权限管理**：用户可删除自己的评论，管理员可删除所有评论。
    *   **级联删除**：笔记删除时，关联评论自动清理。

### 3. 广场大喊 (Square Shout) - **NEW!**
*   **匿名树洞**：全匿名聊天室，所有用户统一昵称为“大蒜”，头像为“蒜”。
*   **即焚机制**：
    *   **阅后即焚**：进入聊天室不加载历史记录，只看当前新消息。
    *   **定时清理**：后端自动清理 10 分钟前的历史消息，不留痕迹。
*   **极速体验**：本地消息立即上屏，无需等待网络；利用 Watch 监听实现多人实时同步。

### 4. 个人中心 & 管理员 (Profile & Admin)
*   **个人信息**：显示 OpenID（点击可复制）。
*   **管理员后台**：
    *   **审核发布**：管理员可查看所有“审核中”的笔记，进行“通过”或“拒绝”操作。
    *   **审核删除**：管理员可查看用户提交的“删除申请”，决定是否从数据库物理删除。
*   **权限控制**：基于 `admins` 集合严格控制管理员权限，普通用户无法访问审核接口。

## 数据库设计 (Cloud Database)

### 1. `notes` 集合
存储所有笔记数据。
*   `_id`: 唯一标识
*   `_openid`: 创建者 OpenID
*   `content`: 笔记内容 (Markdown)
*   `images`: 图片 FileID 数组
*   `visibility`: 'public' | 'private'
*   `status`: 'draft' (草稿) | 'pending' (审核中) | 'published' (已发布) | 'pending_delete' (申请删除)
*   `createTime`: 创建时间
*   `wordCount`: 字数统计

### 2. `admins` 集合
存储管理员名单。
*   `_openid`: 管理员的 OpenID

### 3. `chat_messages` 集合
存储“广场大喊”的临时聊天记录。
*   `content`: 消息内容
*   `nickName`: 固定为 "大蒜"
*   `createTime`: 发送时间
*   `_openid`: 发送者 ID (用于区分自己和他人，前端不显示)

## 部署说明

1.  **云函数部署**：
    *   `login`: 获取用户 OpenID。
    *   `note`: 处理笔记的增删改查及审核逻辑。
    *   `admin`: 获取管理员列表及权限校验。
    *   `shout`: 处理聊天消息发送及自动清理旧消息。
    *   请在开发者工具中右键 `cloudfunctions` 下的每个文件夹，选择“上传并部署：云端安装依赖”。

2.  **数据库权限**：
    *   `notes`: **“仅创建者可读写”** (推荐)。公开笔记的读取现已通过云函数代理，无需放开数据库读取权限，保障隐私安全。
    *   `admins`: “所有用户可读，仅创建者可读写”。
    *   `chat_messages`: **“所有用户可读，仅创建者可读写”** (必须设置，否则无法收到他人消息)。
    *   `comments`: **“所有用户可读，仅创建者可读写”** (必须设置)。

3.  **其他**：
    *   需要在 `app.json` 中配置 `lazyCodeLoading` 以优化启动速度。
    *   图标资源建议使用 PNG 格式以获得最佳兼容性。
