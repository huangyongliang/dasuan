# 大蒜助手 (Garlic Assistant)

一个轻量级的微信小程序工具，专注于提供精准的天气查询和日历服务。

## 核心功能

### 1. 天气预报 (Weather)
*   **实时天气**：展示当前温度、天气状况（如晴朗、多云）及风速。
*   **未来七天预报**：提供未来一周的每日天气概况、温度范围（最低温~最高温）。
*   **多城市支持**：内置常用城市列表（深圳、北京、上海、广州、成都、杭州、武汉、天门、西安、南京），支持快速切换查询。
*   **数据来源**：集成 Open-Meteo 气象数据接口，精准可靠。

### 2. 日历服务 (Calendar)
*   **公历日期**：显示完整的公历年月日及星期。
*   **农历转化**：内置轻量级农历算法，支持显示农历年份（含生肖）及日期（如：农历 甲辰年(龙) 十一月廿九）。

### 3. 个人中心 (Profile)
*   **极简设计**：展示用户基本信息。
*   **权限管理**：保留了基于云开发的基础用户身份识别功能。

---

## 技术亮点

*   **原生开发**：基于微信小程序原生框架 (WXML, WXSS, JS) 构建，性能优异。
*   **自定义组件**：
    *   **Custom TabBar**：完全自定义的底部导航栏，样式更灵活。
    *   **PageContainer**：使用原生页面容器实现流畅的底部弹窗交互。
*   **算法集成**：前端集成农历转换算法，离线即可快速计算农历日期。
*   **性能优化**：启用了按需注入 (`lazyCodeLoading`)，提升启动速度。

## 部署说明

1.  **环境要求**：
    *   微信开发者工具最新版。
    *   开通微信云开发环境（用于基础用户鉴权）。

2.  **网络配置**：
    *   需要在微信后台“开发设置”中将 `https://api.open-meteo.com` 添加到 `request` 合法域名列表（开发调试阶段可在工具中勾选“不校验合法域名”）。

3.  **云函数部署**：
    *   上传并部署 `login` 云函数，用于获取用户 OpenID。
